# Mushroom — Навігатор для грибника

Ультралегкий, енергоефективний та 100% нативний Android-додаток для збору грибів, лісової навігації, фіксації грибних місць та роботи з офлайн OpenStreetMap (OSM) картами.

Побудований виключно на **нативному Android SDK (Kotlin)** без важких сторонніх бібліотек (Google Play Services, Mapbox, Osmdroid, Room тощо):
- ⚡ **Розмір APK:** **~134 KB** (жорсткий ліміт < 1 МБ).
- 🧠 **Використання RAM:** **< 20 МБ** (економне LruCache кешування тайлів).
- 🔋 **Максимальна енергоефективність:** WakeLock утримується лише під час активного запису треку. При зупинках частота опитування GPS зменшується, а при тривалій стоянці додаток переходить у глибокий сон із пробудженням від апаратного датчика руху.
- 📱 **Повноцінна робота у фоні:** Трек пишеться навіть при заблокованому екрані смартфона в кишені.
- 💾 **Незнищенне сховище `/sdcard/mushroom`:** Налаштування, мітки, треки та карти зберігаються у загальнодоступній папці користувача і не видаляються системою при знесенні програми.

## 🚀 Автоматична збірка APK

Для швидкої компіляції підписаного релізного APK на будь-якому комп'ютері використовуйте готові скрипти:

### 🪟 Windows:
```cmd
_BUILD_apk_.bat
```

### 🐧 Linux & 🍎 macOS:
```bash
chmod +x _BUILD_apk_.sh
./_BUILD_apk_.sh
```

Скрипти автоматично:
1. Визначають архітектуру та операційну систему.
2. Завантажують портативний **OpenJDK 17**, **Gradle 8.7** та **Android Command-Line Tools** у разі відсутності.
3. Підписують релізний APK ключем `app/keystore/debug.keystore` (гарантія однакового цифрового підпису для оновлень поверх).
4. Копіюють готовий релізний файл у корінь проекту:
   `Mushroom_yy.MM.dd_HHmm.apk` (~134 KB).

## 🛠️ Архітектура та функціонал

### 1. Офлайн OSM карти (100% Native Canvas)
- Власний нативний рушій **Slippy Map** на базі Android `Canvas`.
- Плавне перетягування (Pan) та масштабування двома пальцями (Pinch-to-zoom).
- Кнопки швидкого зуму `＋` / `－` та центрування на собі `📍 Центр`.
- Багаторівневе кешування: RAM LruCache + дискове збереження тайлів у `/sdcard/mushroom/maps/tiles/{z}/{x}/{y}.png`.
- Повна автономність у глухому лісі без мобільного зв'язку.

### 2. Завантаження карт по країнах та регіонах
- Меню $\to$ **Карти**.
- Вибір країни (Україна, Польща тощо).
- Список регіонів (областей) із **чекбоксами** для вибору декількох областей одночасно.
- Розрахунок орієнтовної кількості тайлів для масштабів z10..z13.
- Фонове завантаження з діалогом прогресу та можливістю зупинки.

### 3. Мітки грибних місць (Waypoints)
- Кнопка **🍄 +Мітка**: зберігає координати з типом гриба (Білий гриб, Лисичка, Підосиковик, Опеньки, Маслюк, Автомобіль/База тощо) та приміткою.
- **Список міток**:
  - Відображає точну відстань (у метрах/км) та компасний напрямок (Пн, Сх, Пд-Зх тощо) від вашого поточного положення.
  - **Чекбокси**: вибіркове ввімкнення/вимкнення показу конкретних міток на карті.
  - Натискання на мітку центруює карту на збереженій точці.
  - Збереження у базі SQLite та у файлі `/sdcard/mushroom/markers/markers.json`.

### 4. Запис та експорт треків
- Кнопка **⏺️ REC**: запуск/зупинка фонового запису пройденого шляху.
- Фільтрація GPS-шуму: точки фіксуються лише при зміщенні $\ge 2.5$ м і точності супутників $\le 35$ м (жодних «павутинок» при стоянці на місці).
- Відображення живої лінії треку різними кольорами.
- **Список треків**:
  - Перегляд довжини (км), тривалості та кількості точок.
  - **Чекбокси**: вибір, які треки показувати на карті.
  - Клік по треку автоматично центрує та масштабує карту під межі маршруту.
  - Автоматичний експорт у стандартний формат **GPX** у папку `/sdcard/mushroom/tracks/`.

### 5. Позиціонування, компас та орієнтація
- Поточне місцезнаходження зафіксоване в центрі екрана.
- **Апаратний компас**: плавна стрілка на Північ та індикатор азимута в градусах.
- **Індикатор руху**: динамічна стрілка напрямку ходьби (курсу).
- Перемикач орієнтації: **Північ зверху** (фіксована карта) або **За курсом** (карта обертається за компасом).
- Верхня інфо-панель: широта/довгота, висота над рівнем моря, точність GPS, швидкість ходьби.

### 6. Спільне сховище `/sdcard/mushroom`
Структура файлів на пристрої:
```
/sdcard/mushroom/
├── maps/
│   └── tiles/{z}/{x}/{y}.png    # Кеш офлайн карт
├── markers/
│   └── markers.json              # Збережені грибні мітки
├── tracks/
│   ├── tracks.json               # Список треків
│   └── track_<id>.gpx            # Стандартні GPX файли
├── settings/
│   └── settings.json             # Резервна копія налаштувань
└── logs/                         # Діагностичні логи (при debug)
```
> При видаленні або оновленні додатка папка `/sdcard/mushroom` повністю зберігається. При повторному встановленні всі карти, мітки та треки підтягуються автоматично!
